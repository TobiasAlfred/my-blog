#### 📌 01 前言

关于央行数字货币DCEP的话题已逐渐降温，此前DCEP几乎被传得呼之欲出，但细看下来这更多是各路媒体的一厢情愿。 毕竟作为替代M0的核心金融基础设施，DCEP如果不经历反复测试和推演就贸然推出，必然会对我国货币体系产生不可预估的负面影响。 就DCEP和人民币国际化的发展路径，笔者认为应当分两步走：

> 第一步：建立稳定的国内数字货币运行体系，优化传统纸币流通的弊病，为国际社会树立数字货币运行范本； 第二步：牵头建立国际数字货币汇兑管理平台，完善管理规则、成立类IMF的新型国际货币权威机构，实现弯道超车成为规则制定者。

关于央行数字货币DCEP的技术和运行细节，笔者在《[何必非要去中心化——浅析央行数字货币基于UTXO模型的设计路线](#wechat_redirect)》和《[央行数字货币DC/EP全景解析：运行机制、场景应用及前瞻性分析](#wechat_redirect)》两篇文章中已经做了详细预测和分析。 本文将从香港金管局和泰国央行合作开发的**Inthanon-LionRock项目**出发，详实解析央行DCEP国际化路线、以及建立国际数字货币汇兑平台的可行性路径。

#### 📌 02 关于Project Inthanon-LionRock

Inthanon-LionRock项目是泰国央行（BOT）与香港金管局（HKMA）联合发起的分布式账本技术（DLT）跨境支付探索项目，核心目标是解决当前多层级跨境转账体系的痛点： ✅ 低效率 ✅ 高成本 ✅ 可追溯性不足 ✅ 监管困难

### 项目核心特征

1. **技术路径**：在R3联盟的Corda区块链平台上搭建，引入成熟商业解决方案验证政商联合区块链应用的可行性
2. **定位**：2019年9月启动的POC（概念验证）项目，尝试在香港LionRock数字货币网络和泰国Inthanon数字货币网络之间搭建「走廊网络」，实现港币和泰铢的线上兑换与转账
3. **参与方**：港泰双方合计超十家金融机构参与，港方包括汇丰银行、香港首家虚拟银行众安银行（ZA Bank）
4. **关键价值**：虽然不是大陆央行主导，但香港金管局的本次实验，某种程度上为央行DCEP的未来发展路径做了有效前置验证，成果显著。

> 💡 名词说明：
>
> - CBDC：即中央银行数字货币，央行DCEP属于CBDC的一种，W-CBDC代表批发型央行数字货币
> - 原子化PvP（Payment vs. Payment）：外汇交易中，一方支付本币的同时另一方必定支付外币，不会出现单边支付风险，避免交易信用风险

#### 📌 03 项目鸟瞰图

#### 3.1 项目背景

Inthanon-LionRock项目致力于优化批发性大额跨境支付场景，实现流程化协调、实时转账、原子化PvP结算。项目是港泰双方独立研究成果的联合延伸：

- 2017年香港金管局启动**LionRock项目**，探索W-CBDC的优势与风险，研究基于DLT系统的CBDC代币和债券发行，覆盖审计、参与者延展性、监管可追溯性、支付系统整体评价四大方向
- 2018年泰国央行启动**Inthanon项目**，研究利用DLT增强泰国金融基础设施协同能力，分两个阶段完成了现金代币化、债权代币化、流动性供给机制、债权生命周期管理等课题验证

2019年双方联合启动Inthanon-LionRock项目，重点研究四大方向：

1. 跨境结算效率优化
2. 流动性管理效率提升
3. 本地化监管要求嵌入
4. 可拓展性架构设计

#### 3.2 整体愿景

项目通过建立走廊网络，实现跨境资金实时转账和外汇兑换，减少结算层级、提升效率、降低成本：

1. 基于共享DLT跨境网络和原子化PvP交易，实现跨境资金高效转移和外汇快速兑换
2. 实现本地网络与走廊网络无缝衔接，评估项目功能性与非功能性表现
3. 提升跨境结算效率、流动性管理效率和链上监管水平
4. 孵化央行与商业银行协作环境，利用DLT潜力升级现有金融基础设施

#### 3.3 核心目标

#### 3.3.1 功能性目标

1. **存托凭证（DR）兑换**：走廊网络中设计DR作为货币价值载体，包括代表港币的DR-HKD和代表泰铢的DR-THB，支持DR与本地网络CBDC的双向自动转换
2. **跨境资金转移**：实现P2P即时银行间跨境资金转移
3. **外汇兑换**：支持现行汇率、询价、链下安排三种汇率机制，确保港元和泰铢互换的原子化PvP交易
4. **嵌套外汇兑换的跨境资金转移**：在跨境资金转移指令中嵌套外汇兑换指令，一步完成交易
5. **流动性管理**：设立交易队列优先级机制、多资产流动性节约机制（MLSM）解决拥堵问题，提供即时流动性注入避免死锁
6. **监管合规**：实时监控HKD和THB钱包与交易信息，纳入泰国非居民账户管理要求

#### 3.3.2 非功能性目标

✅ 交易原子性：避免交易仅部分执行 ✅ 结算最终性：确保交易不可回滚 ✅ 系统弹性：作恶节点存在时仍可稳定运行 ✅ 交易隐私性：最低限度披露隐私信息

#### 3.4 架构设计

走廊网络基于Corda平台搭建，作为桥梁联通香港和泰国的本土CBDC支付网络：

- **核心运营节点**：由HKMA和BOT共同维护，承担DR发行销毁、流动性供给、监管协调职能
- **参与银行节点**：所有参与银行在本土网络和走廊网络均运行自有节点，每日执行合规调度
- **共识机制**：采用Corda的notary节点验证模式，仅交易参与方和notary节点验证交易，兼顾TPS、隐私性与安全性
- **特殊角色**：走廊网络设置外币DR流动性提供方，实验阶段由运营节点担任

#### 📌 04 走廊网络详解

#### 4.1 模型设计

#### 4.1.1 传统跨境支付的痛点

当前跨境资金转移平均手续费率高达7%，高度依赖代理银行体系，存在五大核心问题：

1. **运营效率低**：多参与方通信标准不统一、时区差异导致交易耗时长达数天
2. **流动性管理难**：银行需要在多国开设境外账户（nostro account），多账户流动性管理成本高
3. **结算风险高**：存在单边支付失败的信用风险
4. **可追溯性差**：交易中间环节不透明，容易产生不合理费用
5. **监管难度大**：不同国家/地区监管要求差异大，合规成本高

#### 4.1.2 预选模型探索

业内针对跨境支付痛点提出两类解决方案：

| 模型类型       | 核心特征                                                     | 变体分类                                                     |
| -------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 开放参与式模型 | 央行允许外国实体参与本国RTGS（实时清算系统），央行对本国货币保持完全掌控 | 1. 允许外国央行参与 2. 允许准入外国结算银行参与 3. 允许所有符合资质银行参与 |
| 资产扩张模型   | RTGS网络支持参与者持有并直接转账外币                         | 1. 本币RTGS支持本外币结算 2. 多币种RTGS支持所有跨境结算 3. 独立多币种走廊网络支持跨境交易（本项目采用） |

本项目采用的独立走廊网络模型优势：各主权地区可独立管理本土RTGS网络，同时联合管理共同的走廊网络，兼顾主权货币控制权与跨境结算效率。

#### 4.1.3 最终模型特征

1. 一国央行是CBDC的唯一发行方和赎回方
2. 本土结算网络独立于走廊网络，非居民银行不允许参与本土网络、持有CBDC
3. 走廊网络仅用于跨境结算，以DR作为货币价值载体
4. 参与银行可在走廊网络持有DR-THB和DR-HKD，实现具备最终性的P2P交易结算
5. 统一的流动性管理机制与监管要求覆盖所有走廊网络交易

| 走廊网络角色     | 职能                                                         |
| ---------------- | ------------------------------------------------------------ |
| 营运节点         | HKMA和BOT联合管理，负责DR发行销毁、DR与CBDC兑换、拥堵解决、监管合规 |
| 参与方节点       | 发起跨境交易结算，管理本外币流动性                           |
| 外币流动性供给者 | 死锁状态下提供日内临时性流动性                               |

#### 4.2 核心功能

#### 4.2.1 存托凭证DR转换

- 参与银行需将本土网络持有的足值CBDC兑换为走廊网络DR，本土央行节点充当网关，确保DR新增价值与CBDC销毁价值完全一致
- 支持DR到CBDC的反向转换，银行每日终了可将DR余额转换为CBDC存入本土网络钱包

#### 4.2.2 跨境资金转移

走廊网络支持三类跨境转账场景：

1. 发送DR-LCY（本币存托凭证）到外国银行
2. 发送DR-FCY（外币存托凭证）到另一本国银行
3. 发送DR-FCY到外国银行

> ❌ 不支持发送DR-LCY到另一本国银行：该场景可直接在本土网络完成，避免占用走廊网络资源

交易提交后要么即时执行（流动性充足），要么按优先级进入队列依次执行。

#### 4.2.3 外汇交易执行

所有交易均通过原子化PvP完成，支持三种汇率决定机制：

1. **现行利率（Board Rate）**：系统自动选择网络中最优报价完成兑换，需求方为market taker，做市商为market maker
2. **报价（RFQ, Request for Quote）**：需求方可向多个潜在对手方询价，选择最优报价确认执行
3. **链下安排（Off-Corridor Arrangement）**：支持走廊网络参与银行代非参与银行完成外汇交易，双方提交相同参数的交易请求后系统自动撮合

#### 4.2.4 嵌套外汇交易的跨境资金转移

整合外汇交易与跨境转账指令，系统先完成外汇兑换，再执行资金转移，一步完成交易。

#### 4.2.5 流动性管理

走廊网络通过四大机制实现高效流动性管理：

1. **交易队列机制**：流动性不足时交易按优先级进入队列，资金充足后依次执行
2. **MLSM多资产流动性节约机制**：定期触发系统拥堵解决方案，覆盖单向付款和原子化PvP交易
3. **及时流动性供给（ALP）**：死锁状态下自动将本土CBDC转换为DR注入，或从流动性提供方借入外币（当日需归还）
4. **代币转换机制**：DR与CBDC双向随时转换，支持流动性灵活调度

#### 4.2.6 监管要求

1. **实时监管**：央行可监控全生命周期交易、外汇实时报价、DR与CBDC转换情况、日内外币借贷情况，及时调整货币流通量、触发合规预警
2. **泰国特殊监管要求**：基于泰铢监管历史经验，走廊网络泰铢账户等同于NRBA（非居民泰铢账户），单个实体所有泰铢账户日终余额合计不得超过2亿泰铢，超额部分系统自动完成外汇清算

#### 📌 05 技术设计及发现

#### 5.1 系统架构

POC测试基于三个异构独立的Corda多币种网络，保证网络互操作性，代币发行转换基于对央行节点的完全信任：

1. **走廊网络Corda节点**：参与银行运行普通节点，央行联合运行运营节点，通过CorDapps提供核心功能
2. **本土网络Corda节点**：参与银行和央行各自运行节点，央行负责代币化和监管，CorDapps提供DR转换功能
3. **API层**：作为DLT节点与Web客户端的中间件，通过RPC与Corda节点通信，处理客户端请求、用户认证授权
4. **UI层**：Web GUI界面，支持用户操作、发起交易请求

#### 5.2 走廊网络应用架构

#### 5.2.1 核心模块

1. **核心与插件**：继承自泰国Inthanon项目，提供金融资产模型、核心结算、净头寸结算支持，增强MLSM机制适配外汇交易
2. **公共服务**：包括网络间代币转换、监管监控、流动性供给、外汇汇率广播等服务，实验阶段由运营节点代理
3. **跨境付款模块**：将交易定义为智能合约，支持嵌套外汇交易功能，在单次DLT交易中完成全部流程
4. **外汇交易模块**：开发智能合约实现三种汇率机制，单独合约监控结算过程满足监管要求
5. **流动性供给模块**：支持从流动性提供商获取流动性、或从本土网络转换代币获取流动性，解决MLSM堵塞问题

#### 5.2.2 代币转换机制

代币转换是本土CBDC转换为走廊网络DR的过程，不涉及所有权转移，需要两个DLT网络的智能合约协同工作，基于对央行节点的信任实现安全转换。

#### 5.3 非功能性特性

✅ **原子性**：保障交易执行完整性 ✅ **最终性**：Corda notary节点确认交易不可回滚 ✅ **弹性**：双网络节点设置+代币转换机制，保障故障修复后可恢复运行 ✅ **隐秘性**：交易信息最低限度披露，身份匿名，报价流程保护参与者隐私

#### 📌 06 新框架模式下的交易全流程

#### 6.1 新流程演示

仍以「泰国公司向香港公司支付100万港元货款」为例，走廊网络下的交易流程：

1. 泰国公司通知A银行向香港公司的Z银行账户支付100万港元
2. A银行确认Z银行是走廊网络参与银行
3. A银行将本土网络中价值400万泰铢的CBDC转换为走廊网络等值DR-THB
4. A银行选择「嵌套外汇交易的跨境资金转移」方式发起交易
5. 系统匹配到Y银行提供最优汇率：4 DR-THB兑换1 DR-HKD
6. 原子化结算完成：A银行获得100万DR-HKD并转账至Z银行，Y银行获得400万DR-THB，两步骤同时完成
7. Z银行确认交易后将资金划拨至香港公司账户

#### 6.2 核心改良点

1. **结算效率大幅提升**：实时跨境支付+PvP外汇结算，无需中间人，交易直接在银行双方完成
2. **流动性效率提升**：MLSM机制最大化流动性有效性，CBDC代币替代外币账户功能
3. **监管合规成本降低**：所有交易实时上报，减少事后报告流程，内置监管预警
4. **可拓展性强**：当前仅10家银行参与的模型可直接拓展到更多国家、更多参与方的场景

#### 📌 07 结语

香港作为中国金融改革最前沿的试验田、以及最重要的人民币离岸金融中心，其货币体系的探索价值不言而喻。 Inthanon-LionRock项目表面是香港金管局与泰国央行的数字货币实验，本质上是为未来央行DCEP在跨境支付、外汇交易领域的广泛应用做了突破性前置验证，值得深入剖析。

从泰国最高峰因他农山到代表香港精神的狮子山，背后是两国/地区对数字货币金融创新的探索。暗涌的金融市场、激荡的思维碰撞，不变的是创新的魄力与处变不惊的心境。 世界货币格局的旧土已然松动，未来鹿死谁手犹未可知，求思求变，才是突破时局的最佳方式。
